# Киіз үй 3D

Қазақтың киіз үйінің интерактивті 3D моделі. Пәнаралық жоба: **тарих**, **математика** және **физика**.

## Мүмкіндіктері
- Модельді айналдыру, жақындату, ішіне кіру (Сырттан / Ішінен / Жоғарыдан)
- «Құрастыру» анимациясы: кереге → есік → шаңырақ → уықтар → туырлық → үзік
- Киізді мөлдір ету немесе алып тастау, тек сүйегін көру
- Бөліктердің атаулары мен сипаттамасы (шаңырақ, күлдіреуіш, уық, кереге, есік, туырлық, үзік, ошақ, төр)
- Қанат саны (4–12) мен кереге биіктігі бойынша есептеулер: диаметр, еден ауданы, көлем, уық саны мен ұзындығы, киіз ауданы
- Жылу шығыны: Q = λ · S · ΔT / d
