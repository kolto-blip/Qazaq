# Ақылды киіз үй

Пәнаралық жоба: **Тарих + Физика + Математика + Информатика**.

## Бөлімдері
- **Маусымдар (Тарих + Физика):** қыс (қыстау), көктем (көктеу), жаз (жайлау), күз (күзеу). Мезгіл 3D көріністі (қар, күзгі жапырақ, түрілген туырлық), сыртқы температураны және датчик симуляциясын өзгертеді.
- **Құрылысы (Тарих):** шаңырақ, күлдіреуіш, уық, кереге, есік, туырлық, үзік, түндік, ошақ, төр. 3D модельде «Құрастыру» анимациясы бар.
- **Тарихы:** сақтардан ЮНЕСКО тізіміне дейін (2014).
- **Геометрия (Математика):** диаметр, еден ауданы πR², көлем (цилиндр + қиық конус), уық саны мен ұзындығы, киіз ауданы.
- **Жылу (Физика):** Q = λ · S · ΔT / d, киіздің жылу өткізгіштігі λ ≈ 0,04 Вт/(м·К).
- **Датчик (Информатика):** ішкі температураның тәуліктік симуляциясы, автомат режимі (T < 18 °C — «отын сал», T > 24 °C — түндік ашылады) және Arduino коды (DHT22, LCD 1602, зуммер, SG90 серво).

## Іске қосу
`index.html` файлын браузерде ашыңыз. Технология: Three.js r128.
