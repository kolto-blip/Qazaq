Қазақ хандығы

Қашан құрылды?

1465 жылы. 560 жыл бұрын.

Кімдер құрды?	

Керей және Жәнібек хандар. Олар қазақтарды біріктірді.

Қайда құрылды?

Жетісу жерінде, Шу және Талас өзендерінің жанында.

Не істеді?	
- Көшіп-қонып мал бақты (жылқы, қой, түйе)
- Киіз үйде тұрды
- Батырлары елді қорғады
- Атақты хандар: Қасым хан, Есім хан, Тәуке хан, Абылай хан

Неліктен маңызды?
Осы хандықтан біздің еліміз — Қазақстан пайда болды. Біз — сол хандардың ұрпағымыз!

Қазіргі таңда Қазақстан мемлекеті болып қалыптасты. Қазір біз Тәуелсіз елміз. Елімізді басқаратын өз президентіміз бар. Ата заңымыз бар. 

Рәміздер: Ту, елтаңба, әнұран

Тіліміз: қазақ
